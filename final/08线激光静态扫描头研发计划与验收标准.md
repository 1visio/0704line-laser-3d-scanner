# 线激光静态扫描头八周研发计划与验收标准

> 文档版本：V1.0
> 编制日期：2026-07-10
> 适用阶段：第一版静态扫描头光学、标定与计量可行性验证
> 方案基线：12MP 高精度方案，1 m 名义工作距离，漫反射表面

## 1. 项目目标

### 1.1 总体目标

基于已经完成选型和加工的刚性线激光扫描头，在 **1 m ±100 mm** 工作距离内，完成约 **500 mm 宽单条三维轮廓**的采集、标定、重建和计量验证，形成可复现的静态扫描头技术基线。

本阶段采用分层精度目标：

1. 500 mm 有效区域内横向物方采样间隔不大于 0.2 mm/点。
2. 固定漫反射平面的 Z 向重复性中位数不大于 0.2 mm。
3. 全验证集三维绝对误差 RMSE 不大于 0.5 mm。
4. 全场绝对 RMSE 不大于 0.2 mm 作为冲刺指标，不作为本阶段硬性通过条件。

### 1.2 本阶段边界

本阶段只验证固定姿态下的一条三维轮廓，不验收以下内容：

- 俯仰扫描机构及运动控制；
- 0.5 m × 0.5 m 面形貌重建；
- 编码器、相机和激光器的硬件触发同步；
- 机器人末端安装、手眼标定和轨迹联动；
- 深色、透明及高反光材料上的硬性精度指标；
- 面向产品部署的 C++ 实时软件。

静态扫描头通过本计划的全部阶段门后，再启动俯仰扫描与机器人集成阶段。

## 2. 已知设计基线与使用原则

| 项目 | 当前基线 |
|---|---|
| 相机 | 大恒 ME2P-1230-23U3M，4096 × 3000，黑白全局快门 |
| 镜头 | 大恒 HN-P-2524-20M-C1.1/1，25 mm，1.1 英寸，前螺纹 M37 × 0.5 |
| 激光器 | 450 nm 蓝光，Powell 透镜，30°扇角；实际功率以铭牌为准 |
| 滤光片 | 450 nm 窄带滤光片 |
| 名义工作距离 | 1000 mm |
| 验证工作窗口 | 900–1100 mm |
| 目标有效线宽 | 不小于 500 mm |
| 当前支架基线范围 | 约 70–170 mm |
| 推荐初始基线 | 150–170 mm |
| 正式验收表面 | 哑光白色或浅色漫反射表面 |
| 研发软件 | Python、OpenCV、相机厂商 SDK |

使用原则：

- 第一版支架作为可调实验结构使用，先测量其性能，不预先进行大范围结构改造。
- 每次改变基线、相机姿态、激光器姿态或镜头焦点后，原激光平面标定立即失效，必须生成新标定版本。
- 每轮实验只改变一个主要变量，禁止同时调整机械、曝光和算法后直接比较结果。
- 标定数据、调参数据和最终验收数据必须分开保存。

## 4. 八周阶段计划

### 第1周：安全与基线建立

主要工作：

- 记录相机、镜头、滤光片、激光器、支架和线缆的型号、序列号及实物状态。
- 核对激光器铭牌中的波长、输出功率、安全等级和控制方式，消除文档中 50 mW/80 mW 的不一致。
- 完成遮光、光束终止、护目、警示、钥匙/电源控制及实验区隔离。
- 测量并记录相机光心高度、激光出光中心、基线、激光角度和工作距离。
- 定义坐标系：X 为基线方向，Y 为激光线长度方向，Z 为相机指向工件的工作距离方向。
- 建立实验编号、数据目录和变更记录规则。

交付物：

- 硬件台账；
- 激光安全检查表；
- 扫描头坐标系示意；
- 初始装调照片和关键尺寸记录；
- 首版实验日志。

阶段门：

- [ ] 实物型号和关键参数均有记录。
- [ ] 激光安全措施完成并经现场确认。
- [ ] 相机能够被厂商工具或 SDK 正确识别。
- [ ] 安全措施完成前不允许开启激光器。

### 第2周：图像采集与光学调试

主要工作：

- 使用相机厂商 SDK 和 Python 完成单帧、连续采集和参数读取。
- 默认使用全分辨率无损灰度图，保存帧号、时间戳、曝光、增益和像素格式。
- 扫描曝光时间、增益、光圈、焦点和激光功率组合。
- 采集激光关闭的暗场图和激光开启图，量化背景、峰值、饱和比例、SNR、FWHM 和线长。
- 检查 900、1000、1100 mm 三个位置的景深、覆盖和线宽变化。
- 冻结第一版光学与采集参数。

阶段门：

- [ ] 漫反射平面上的有效激光线长度不小于 500 mm。
- [ ] 中央 80% 区域的光条 FWHM 为 3–6 px。
- [ ] 中央 80% 区域 SNR 不小于 10。
- [ ] 有效区域内无大面积饱和，饱和像素比例小于 1%。
- [ ] 最终曝光条件下全分辨率采集速度不低于 15 fps。
- [ ] 连续 30 分钟采集丢帧率小于 0.1%。

### 第3周：相机内参标定

主要工作：

- 准备尺寸、公差和平面度可追溯的高精度 ChArUco 或棋盘格标定板。
- 在 900、1000、1100 mm 及图像中心、四角采集不少于 20 个有效姿态。
- 保证标定板在不同姿态下覆盖图像主要区域，并包含适度俯仰和偏航。
- 将数据分为标定集和独立留出集；留出集不得参与参数拟合。
- 输出内参矩阵、畸变参数、逐图残差和图像空间残差分布。

阶段门：

- [ ] 标定集重投影 RMS 不大于 0.2 px。
- [ ] 留出图像无明显方向一致的边缘系统残差。
- [ ] 标定板尺寸、单位和坐标定义写入标定元数据。
- [ ] 标定失败时优先补充边缘姿态，不直接增加模型复杂度。

### 第4周：亚像素光条中心提取

主要工作：

- 执行暗场扣除、窄带增强、ROI 限制和连通性过滤。
- 针对近似横向光条，逐列提取候选灰度剖面。
- 先实现灰度重心或一维高斯拟合，输出亚像素中心、峰值、FWHM 和置信度。
- 使用连续性约束抑制离群点，不使用会抹平真实台阶的强平滑。
- 只有基础算法无法达到重复性门槛时，才评估 Steger/Hessian 方法。
- 使用固定平面连续图像评估中心位置抖动和断线区域。

阶段门：

- [ ] 漫反射平面有效中心点比例不小于 95%。
- [ ] 光条中心在整条有效范围内无系统性跳线或多线误选。
- [ ] 处理结果包含置信度和有效性标志。
- [ ] 同一数据重复运行得到一致结果。

### 第5周：激光平面标定与三角重建

主要工作：

- 在多个已知标定板姿态上采集激光交线。
- 使用相机内参将交线像素反投影到各标定板平面。
- 对三维交线点先做异常点过滤，再用最小二乘拟合激光平面。
- 保留部分标定板姿态作为激光平面独立验证集。
- 对光条中心像素构造相机射线，与激光平面求交得到三维点。
- 明确坐标方向、毫米单位、无效点规则和数值稳定性检查。

阶段门：

- [ ] 留出姿态的点到激光平面 RMS 不大于 0.3 mm。
- [ ] 平面法向量方向和坐标轴方向固定且有说明。
- [ ] 三维轮廓无镜像、翻转、尺度数量级或单位错误。
- [ ] 退化射线、负深度和无穷交点能够被标记为无效。

### 第6周：计量验证

主要工作：

- 在 900、1000、1100 mm 三个工作距离测试高平面度漫反射平板。
- 在视场左、中、右位置测试 0.5、1、5、10 mm 标准台阶或量块。
- 0.2 mm 台阶仅用于分辨能力探索，不参与硬性绝对精度判定。
- 每个正式工况连续采集 100 帧。
- 预热 15 分钟后执行 30 分钟热漂移测试。
- 输出误差直方图、空间热力图、完整率曲线、重复性和异常点分布。

阶段门：

- [ ] 达到第7节全部核心验收指标。
- [ ] 标定数据和验证数据完全分离。
- [ ] 所有失败工况均能追溯到原始图像和配置。
- [ ] 形成第一版误差预算与根因排序。

### 第7周：针对性迭代与配置冻结

主要工作：

- 优先使用现有支架的 150–170 mm 基线范围进行测试。
- 按“光条质量 → 中心重复性 → 相机标定 → 激光平面 → 机械稳定性”的顺序排查。
- 一次只调整一个主要变量，并保留调整前后的完整数据。
- 如果 Z 向灵敏度不足且遮挡可接受，将扩展到 200–220 mm 作为下一版结构建议，不在当前支架上临时拼接高风险结构。
- 对最佳机械位置做可靠锁紧；必要时提出加强梁、定位台阶或定位销改版建议。
- 冻结机械位置、采集配置、算法参数和标定文件。

阶段门：

- [ ] 使用全新数据重复通过核心指标。
- [ ] 冻结配置具有唯一版本号和完整参数快照。
- [ ] 冻结后未再改变机械位置、焦点或光学元件。
- [ ] 遗留风险和下一版结构建议已记录。

### 第8周：盲测与归档

主要工作：

- 准备未参与标定和调参的盲测数据。
- 从原始图像开始运行完整流水线，自动生成 CSV/PLY 和评估报告。
- 在冻结配置下执行两次独立复测。
- 汇总硬指标、冲刺指标、失败样例和适用边界。
- 给出是否进入俯仰扫描阶段的 Go/No-Go 结论。

阶段门：

- [ ] 两次独立复测均通过全部硬指标。
- [ ] 原始数据、配置、标定和结果之间可以双向追溯。
- [ ] 新环境能够依据说明复现主要结果。
- [ ] 形成下一阶段输入条件与遗留问题列表。

## 5. 软件、数据与接口约定

### 5.1 建议数据组织

~~~text
data/
  raw/
    calibration/
    tuning/
    validation/
    blind_test/
  metadata/
calibration/
configs/
outputs/
  profiles/
  metrics/
  figures/
reports/
~~~

目录可在实际开发开始时按项目代码结构调整，但标定集、调参集、验证集和盲测集不得混用。

### 5.2 采集配置

每次实验至少记录：

- 相机型号、序列号和固件/SDK版本；
- 图像宽高、像素格式、曝光、增益和帧率；
- 镜头光圈、焦点位置和滤光片；
- 激光波长、实际功率档位和控制方式；
- 工作距离、基线、相机姿态和激光器姿态；
- 环境照度、预热时间、样件和实验编号。

### 5.3 标定文件

标定文件至少包含：

- 相机内参矩阵和畸变参数；
- 标定图像尺寸和重投影误差；
- 激光平面法向量与偏置；
- 坐标系、单位和法向量方向；
- 数据集编号、时间戳和配置版本；
- 标定板尺寸及其溯源信息；
- 当前机械配置的唯一标识。

### 5.4 三维结果接口

CSV/PLY 字段固定为：

~~~text
x_mm, y_mm, z_mm, intensity, confidence, valid
~~~

约定：

- 坐标单位统一为毫米；
- intensity 保存中心附近的代表灰度；
- confidence 归一化到 0–1；
- valid 为明确的有效性标志；
- 无效点不得用零值伪装成有效三维坐标。

### 5.5 评估结果

每次正式评估至少输出：

- 有效光条宽度；
- 物方采样间隔；
- FWHM、SNR 和饱和比例；
- 有效点比例；
- 相机重投影 RMS；
- 激光平面留出集 RMS；
- Z 向逐点标准差中位数和 P95；
- 三维绝对误差 RMSE 和 P95；
- 30 分钟热漂移；
- 异常点位置和失败原因分类。

## 7. 核心验收标准

| 类别 | 硬性验收标准 |
|---|---|
| 工作范围 | 名义工作距离 1 m，验证窗口 900–1100 mm；有效光条宽度不小于 500 mm |
| 横向采样 | 500 mm有效区域内物方采样间隔不大于 0.2 mm/点 |
| 光条质量 | 中央80%区域 FWHM 3–6 px；SNR不小于10；有效中心点比例不小于95% |
| 连续采集 | 最终曝光条件下全分辨率不低于15 fps；连续30分钟丢帧率小于0.1% |
| 相机标定 | 标定集重投影 RMS 不大于0.2 px |
| 激光平面标定 | 独立留出姿态点到平面 RMS 不大于0.3 mm |
| Z向重复性 | 固定平面连续100帧，逐点Z标准差中位数不大于0.2 mm，P95不大于0.4 mm |
| 三维绝对误差 | 全部留出平面和正式台阶测试点 RMSE 不大于0.5 mm，P95不大于1.0 mm |
| 轮廓完整率 | 漫反射正式验收件有效三维点比例不小于95% |
| 可复现性 | 冻结配置下两次独立复测均通过全部硬指标 |

冲刺指标：

- 全验证范围三维绝对误差 RMSE 不大于 0.2 mm；
- 0.2 mm 台阶在受控条件下能够稳定区分；
- 边缘区域性能与中心区域无明显退化。

冲刺指标未达到不直接判定本阶段失败，但必须记录限制因素和下一步改进方向。

## 8. 失败诊断顺序

验收失败时必须按以下顺序定位：

1. **覆盖与饱和**：检查激光线是否覆盖500 mm、是否存在中心过曝或边缘欠曝。
2. **光条质量**：检查FWHM、SNR、散斑、滤光片、焦点和景深。
3. **中心提取重复性**：固定原始数据比较算法输出，排除机械与采集变量。
4. **相机内参**：检查边缘残差、标定姿态覆盖和标定板精度。
5. **激光平面**：检查交线提取、离群点、板姿态分布和留出误差。
6. **机械稳定性**：检查长槽锁紧、主板弯扭、线缆拖拽和热漂移。
7. **几何灵敏度**：在其他问题排除后，再评估基线扩展到200–220 mm。

同一轮诊断不得同时更改两类以上主要变量。

## 9. 主要风险与控制措施

| 风险 | 影响 | 控制措施 | 触发升级条件 |
|---|---|---|---|
| 激光功率资料不一致 | 安全风险、曝光策略不确定 | 以实物铭牌和说明书为准；确认前采用保守安全措施 | 铭牌或控制方式无法确认 |
| 当前基线偏小 | Z向灵敏度不足 | 优先测试150–170 mm；提升中心提取和机械稳定性 | 重复性不通过且光学/标定问题已排除 |
| 长板与长槽刚度不足 | 外参漂移、热漂移 | 量化后再决定加强梁、定位台阶或定位销 | 固定平面漂移超过门槛 |
| 标定板精度不足 | 形成系统性尺度误差 | 使用尺寸和平面度可追溯的标定板 | 重投影好但三维尺度持续偏差 |
| 蓝光响应较低 | 曝光过长、帧率降低 | 优化功率、光圈、曝光和窄带滤光 | 无法同时满足SNR与15 fps |
| 边缘景深或畸变问题 | 两端精度下降 | 增加边缘标定姿态，优化光圈和焦点 | 边缘误差显著高于中心 |
| 高光与深色表面 | 断线、饱和、散斑 | 本阶段只记录适应性，不作为硬验收 | 下一阶段明确要求多材质 |

## 11. 最终 Go/No-Go 判定

满足以下条件时判定 **Go**，可以进入俯仰扫描阶段：

- 全部硬性验收指标通过；
- 冻结配置下两次独立复测通过；
- 标定、验证和盲测数据严格隔离；
- 原始图像、配置、标定、轮廓和报告可以追溯；
- 激光安全和机械锁紧方式能够支持下一阶段实验；
- 当前限制不会在加入俯仰运动后被不可控放大。

出现以下任一情况时判定 **No-Go**，继续停留在静态阶段：

- Z向重复性或三维绝对误差未达到硬指标；
- 机械漂移导致标定在短时间内失效；
- 500 mm范围内存在无法解释的大面积断线；
- 结果只能在调参数据上通过，盲测无法复现；
- 激光安全条件不完整；
- 无法确定实际硬件配置和标定版本。
